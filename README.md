# 오토클릭 (AutoClick)

Windows용 간단한 자동 마우스 클릭 도구입니다. 클릭 간격을 1ms 단위로 지정하고, 단축키로 시작·정지하며, 원하는 위치 여러 곳을 기억해 순서대로 클릭할 수 있습니다.

## 주요 기능

- **클릭 간격 설정**: 0.1ms ~ 500ms. 슬라이더는 1ms ~ 500ms를 조절하고, 1ms보다 짧은 값(예: `0.5`)은 숫자 칸에 직접 입력합니다. 간격 옆에 초당 클릭 수가 표시됩니다.
- **마우스 버튼 선택**: 왼쪽 / 오른쪽
- **단축키로 시작·정지**: 기본값은 `F8`이며 직접 지정할 수 있습니다. 시작과 정지를 같은 키로 두면 번갈아 동작합니다.
- **단축키 직접 지정**: 입력 칸을 누르고 원하는 키를 누르면 됩니다. `Ctrl`, `Alt`, `Shift` 조합도 가능합니다. (예: `Ctrl + 1`)
- **위치 지정 클릭**: 커서 위치를 여러 곳 기록해 두고 순서대로 돌며 클릭합니다.
  - 기록 키(기본 `F6`)를 누르면 현재 커서 위치가 목록에 추가됩니다.
  - 목록에서 행을 드래그해 순서를 바꾸고, ✕로 삭제하거나 "모두 지우기"로 비웁니다.
  - 목록의 행에 마우스를 올리면 그 위치가 화면에 번호와 함께 잠시 표시됩니다. 클릭을 가로막지 않습니다.
  - 접힌 "위치 지정 클릭" 버튼 오른쪽의 `켜짐 / 꺼짐` 표시를 눌러 위치 모드를 켜고 끕니다.
- **항상 맨 앞 고정**: 오른쪽 위 핀 버튼으로 켜고 끕니다. 기본값은 꺼짐입니다.

## 사용 방법

1. `AutoClicker.exe`를 실행합니다.
2. 클릭 간격과 마우스 버튼을 정합니다.
3. 클릭할 곳에 커서를 두고 시작 키(기본 `F8`)를 누릅니다. 정지도 같은 키입니다.
   - 커서가 이 프로그램 창 위에 있는 동안에는 클릭하지 않고 기다립니다. 창 밖으로 옮기면 클릭이 시작됩니다.
4. 위치 모드를 쓰려면 "위치 지정 클릭"을 펼쳐 위치를 기록하고, `켜짐`으로 바꾼 뒤 시작합니다. 이때는 프로그램이 커서를 직접 옮기며 클릭하므로 클릭 중에는 마우스를 쓰기 어렵습니다. 정지 키로 멈추세요.

### 단축키 지정

| 항목 | 기본값 | 설명 |
| --- | --- | --- |
| 시작 키 | `F8` | 클릭 시작 |
| 정지 키 | `F8` | 클릭 정지 (시작 키와 같으면 토글) |
| 위치 기록 키 | `F6` | 현재 커서 위치를 목록에 추가 |

- 입력 칸을 클릭하면 "키를 누르세요…"가 표시됩니다. 원하는 키나 조합을 누르면 등록되고, `Esc`를 누르면 취소됩니다.
- 위치 기록 키는 시작·정지 키와 같게 지정할 수 없습니다.
- 글자·숫자 키 하나만 지정하면 다른 프로그램에서 입력할 때도 동작합니다. `Ctrl`이나 `Alt`와 함께 쓰는 조합을 권장합니다.
- 윈도우 키 조합은 지원하지 않습니다.
- 단축키와 위치 목록은 저장되지 않으며, 프로그램을 닫으면 기본값으로 돌아갑니다.

## 파일 구성

| 파일 | 설명 |
| --- | --- |
| `AutoClicker.exe` | 실행 파일 (아래 방법으로 만든 결과물) |
| `autoclick_gui.ps1` | 프로그램 소스 (PowerShell + C#) |
| `autoclick_gui.bat` | 소스(`.ps1`)를 바로 실행하는 배치 파일 |
| `autoclick.ico` | 프로그램 아이콘 |
| `autoclick.ps1`, `autoclick.bat` | 초기에 만든 콘솔 버전 (F8 시작/정지, F9 종료) |

## 소스에서 실행 / 빌드

별도 설치 없이 `autoclick_gui.bat`을 실행하면 소스를 그대로 실행할 수 있습니다.

EXE로 만들려면 [ps2exe](https://github.com/MScholtes/PS2EXE) 모듈을 사용합니다.

```powershell
Install-Module ps2exe -Scope CurrentUser
Invoke-ps2exe -inputFile .\autoclick_gui.ps1 -outputFile .\AutoClicker.exe `
  -iconFile .\autoclick.ico -noConsole -STA -title "오토클릭"
```

## 알아둘 점

- **Windows 전용**입니다. Windows 10 / 11에서 만들고 확인했으며, 다른 환경에서의 동작은 확인하지 못했습니다.
- 서명되지 않은 프로그램이라 처음 실행할 때 SmartScreen 경고가 뜨거나 백신이 오탐할 수 있습니다.
- 관리자 권한으로 실행 중인 프로그램에 클릭하려면 이 프로그램도 **관리자 권한으로 실행**해야 합니다.
- 클릭을 받는 프로그램이 처리할 수 있는 속도에는 한계가 있습니다. 너무 짧은 간격(PC에 따라 1~3ms 이하)에서는 렉이 걸리거나 오히려 클릭 수가 줄 수 있습니다. 표시되는 "초당 클릭 수"는 설정값 기준의 계산값이며, 실제 수신 횟수는 이보다 적을 수 있습니다. 환경에 맞는 값을 직접 찾아 쓰세요.
- 시작할 때 내부 구성요소를 한 번 컴파일해서 실행 후 창이 뜨기까지 1~2초 걸립니다.

## 사용 시 주의

예매·선착순 신청 등 **부정한 수단을 이용한 선점이 금지된 곳**에는 사용하지 마세요. 서비스 약관 위반이나 관련 법령 위반이 될 수 있으며, 계정 제재나 법적 책임은 사용자 본인에게 있습니다. 이 도구는 개인 PC 작업 자동화와 클릭 속도 테스트 같은 용도를 전제로 만들었습니다.
